# سامانه حسابداری و مدیریت جامع کسب‌وکار مهرگان
> نگارش ۲.۰.۰ — کاملاً پرتابل، مستقل و آماده بهره‌برداری در هر سیستم‌عامل

نرم‌افزار حسابداری مهرگان با ساختار سبک و مستقل طراحی شده و بدون نیاز به نصب نرم‌افزارهای پیچیده دیتابیس یا تنظیمات دشوار، روی هر سیستمی (ویندوز، لینوکس و مک) با **۱ کلیک** اجرا می‌شود.

---

## 🚀 روش‌های اجرا

### ۱. اجرای فوری در ویندوز (۱ کلیک)
کافیست بر روی فایل زیر دابل کلیک کنید:
```
START_MEHREGAN.bat
```
*(یا فایل `شروع_برنامه_مهرگان.bat`)*

این اسکریپت خودکار:
- بررسی محیط Node.js را انجام می‌دهد.
- وابستگی‌ها و بیلد فرانت‌اند را آماده می‌کند.
- سرور مرکزی را فعال کرده و مرورگر را به آدرس `http://localhost:3000` باز می‌کند.

### ۲. اجرای در لینوکس یا مک
```bash
chmod +x START_MEHREGAN.sh
./START_MEHREGAN.sh
```

### ۳. اجرای دستی از ترمینال / خط فرمان
```bash
npm install
npm run build
npm start
```
سپس مرورگر خود را باز کرده و به نشانی `http://localhost:3000` مراجعه فرمایید.

## 🔑 حساب‌های کاربری پیش‌فرض

| نقش سازمانی | نام کاربری | کلمه عبور پیش‌فرض | سطح دسترسی |
| :--- | :--- | :--- | :--- |
| **مدیر کل سیستم** | `admin` | `admin` | دسترسی نامحدود به تمامی ماژول‌ها، خزانه‌داری، سودآوری و تنظیمات |
| **کارتابل نصاب نمونه** | `installer_ali` | `ali@123` | صرفاً دسترسی به پروژه‌های اختصاص‌یافته به نصاب و ثبت گزارش کار |

---

## 🌐 دسترسی تحت شبکه محلی (LAN / Wi-Fi) برای چند سیستم و تبلت
نرم‌افزار به صورت پیش‌فرض قابلیت کار در شبکه را دارد:
1. برنامه را روی کامپیوتر اصلی (سرور) اجرا کنید.
2. آدرس آی‌پی سیستم در کنسول مشخص می‌شود (مثال: `http://192.168.1.50:3000`).
3. در سایر لپ‌تاپ‌ها، صندوق‌ها یا گوشی‌های متصل به همان شبکه، این آدرس را در مرورگر باز کنید.

---

## 💾 ذخیره‌سازی داده‌ها و پشتیبان‌گیری (Backup)
- کلیه اطلاعات مالی، فاکتورها، اشخاص و تنظیمات در پوشه امن `.mehregan-data/` ذخیره می‌گردند.
- برای پشتیبان‌گیری تنها کافیست از این پوشه یک نسخه کپی بگیرید.
- برای جابجایی نرم‌افزار به یک رایانه دیگر، تمام محتویات پوشه برنامه را به همراه `.mehregan-data` منتقل کنید.
